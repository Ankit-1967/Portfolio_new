# Premium Frontend + AI Portfolio

React + Vite portfolio using only custom CSS and JavaScript animations.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Customize
- Edit `src/main.jsx` for your name, bio, projects, skills, experience, links and contact details.
- Edit `src/styles.css` for the visual system.
- Replace `public/resume.pdf` with your real PDF resume.
- Replace placeholder project mockups in `ProjectCard` with real project images when ready.
- Connect the contact form to Formspree, Resend, EmailJS, a serverless function, or your own backend for real submissions.

## Included
- Responsive layout
- Dark/light Day & Night theme
- Animated stars, clouds, particles and ambient glow
- Typing hero effect
- Scroll progress
- Active-section navigation
- Scroll-triggered reveal animations
- Animated skill bars
- Project filters
- Contact validation
- Loading screen
- Reduced-motion accessibility support
